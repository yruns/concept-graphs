## Issues Identified

### 1. Proxy Anchor Quality
Current proxy selection uses target's co-objects, but sometimes selects unrelated categories:
- `"the pillow on the bed"` -> proxy anchor `[sofa, floor_lamp]`
- floor_lamp is not a natural substitute for "bed"

### 2. ALL + ON Returns Few Results
- `"all throw_pillows on the sofa"` returns only 1 object
- Expected: multiple throw_pillows are visible on sofas
- Issue: ON relation threshold may be too strict

### 3. EDGE-02 Incorrect Pass
- `"the sofa inside the ottoman"` returns 1 object
- This is physically impossible and should return 0

## Recommendations
1. Add semantic similarity scoring to proxy anchor selection
2. Review ON relation z-threshold in spatial_relations.py
3. Add containment size check for INSIDE relation
4. Expand test coverage with more edge cases
